# 배정플립을 우리 학교에서 쓰기

배정플립은 배정고등학교 교육연구부에서 만든 **플립시계 화면보호기**입니다. 시계·날짜와 함께 우리 학교의 **학사일정, 급식, 날씨**를 보여 줍니다. MIT 라이선스로 공개되어 있어 어느 학교나 무료로 쓸 수 있습니다.

설치한 뒤 화면보호기 설정 창에서 **학교 코드, 모서리 문구, 위치** 세 가지만 우리 학교에 맞게 바꾸면 됩니다. 아래 순서대로 하면 20분 정도 걸립니다.

---

## 1. 준비물

- Windows 10 또는 11 PC (따로 설치할 프로그램 없음)
- 인터넷 연결
- 인증키 2개 (무료, 3장에서 받음)
  - **NEIS 인증키:** 학사일정·급식용
  - **기상청 인증키:** 날씨용

---

## 2. 설치

1. https://github.com/bjt82/BaejeongFlip/releases 에서 가장 위(최신) 버전의 **`BaejeongFlip-x.x-Setup.exe`**를 받습니다.
2. 받은 파일을 실행합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누릅니다. 코드 서명이 없는 프로그램이라 나오는 경고입니다.
3. 대기 시간(예: 5분)을 고르고 설치를 마칩니다.
   - 관리자 권한은 필요 없습니다.
   - 제거는 Windows **설정 → 앱**에서 "배정플립"을 찾아 하면 됩니다.

설치하면 **검은 바탕 플립시계(기본 화면)**로 시작합니다.

---

## 3. 인증키 받기 (처음 한 번)

### NEIS 인증키 (학사일정·급식)

1. [NEIS 교육정보 개방 포털](https://open.neis.go.kr)에 회원가입합니다.
2. **마이페이지 → 인증키 발급**에서 인증키를 신청합니다. 바로 발급됩니다.
3. 32자리 영문·숫자 키를 복사해 둡니다.

인증키가 없어도 동작은 하지만, 한 번에 5건까지만 받을 수 있어서 일정이 많은 달에는 일부가 빠집니다.

### 기상청 인증키 (날씨)

1. [공공데이터포털](https://www.data.go.kr)에 회원가입합니다.
2. **"기상청_단기예보 조회서비스"**를 검색해 **활용신청**을 합니다. 보통 자동 승인됩니다.
3. **마이페이지 → 개발계정**에서 **일반 인증키**를 복사해 둡니다.

발급 직후 1시간쯤은 "등록되지 않은 키" 오류가 날 수 있습니다. 잠시 뒤 다시 시도하세요.

> **왜 기상청인가요?** 인증키가 필요 없는 해외 날씨 서버(Open-Meteo)도 쓸 수 있습니다. 하지만 학교망에서는 해외 서버가 막혀 "작업 시간이 초과되었습니다"가 나는 경우가 많습니다. 국내 서버인 기상청은 학교망에서도 잘 됩니다.

## 4. 우리 학교로 바꾸기 (설정 창)

**Windows 설정 → 개인 설정 → 잠금 화면 → 화면 보호기**에서 "BaejeongFlip"을 고르고 **설정** 버튼을 누릅니다.

### ① 모서리 문구

화면 모서리에 작게 나오는 글자입니다. 기본값은 "배정고등학교 / 교육연구부"이니 우리 학교 이름과 부서로 바꿉니다. 비워 두면 표시하지 않습니다.

### ② 학교 정보 (교육청 코드, 학교 코드)

**가장 쉬운 방법: [학교 찾기] 버튼** (1.3 버전부터)

1. 먼저 아래 **인증키** 칸에 NEIS 인증키를 넣습니다. 인증키가 없으면 찾은 학교를 5곳까지만 보여 줍니다.
2. 학교 코드 옆의 **학교 찾기**를 누르고, 학교 이름의 일부(예: `배정고`)를 넣어 **찾기**를 누릅니다.
3. 목록에서 우리 학교를 고르고 **선택**을 누르면 아래 항목이 자동으로 채워집니다.
   - 교육청 코드, 학교 코드
   - 날씨 위치(위도·경도): 학교 주소의 시·군·구 중심 좌표. 프로그램 안의 표에서 찾으므로 인터넷이나 인증키가 필요 없습니다.
   - 모서리 문구: 기본값("배정고등학교")이면 학교 이름으로 바뀝니다.

   기상청 날씨는 5km 단위라 시·군·구 중심이면 충분합니다. 세종시는 시 전체 중심을 쓰고, 주소가 등록되지 않은 일부 기관은 위도·경도를 직접 넣어야 합니다.

**직접 찾는 방법:** 브라우저 주소창에 아래 주소를 넣되, `학교이름` 부분을 우리 학교 이름으로 바꿔 엽니다.

```
https://open.neis.go.kr/hub/schoolInfo?SCHUL_NM=학교이름
```

결과에서 두 값을 찾아 설정 창에 넣습니다.
- `ATPT_OFCDC_SC_CODE`: **교육청 코드** (예: `C10`)
- `SD_SCHUL_CODE`: **학교 코드** (예: `7150136`)

이름이 비슷한 학교가 여러 개 나오면 `SCHUL_NM`(학교 이름)과 `ORG_RDNMA`(주소)를 보고 고르세요.

교육청 코드는 아래 표에서도 찾을 수 있습니다.

| 교육청 | 코드 | 교육청 | 코드 |
|---|---|---|---|
| 서울특별시교육청 | B10 | 경기도교육청 | J10 |
| 부산광역시교육청 | C10 | 강원특별자치도교육청 | K10 |
| 대구광역시교육청 | D10 | 충청북도교육청 | M10 |
| 인천광역시교육청 | E10 | 충청남도교육청 | N10 |
| 전남광주통합특별시교육청(광주) | F10 | 전북특별자치도교육청 | P10 |
| 대전광역시교육청 | G10 | 전남광주통합특별시교육청(전남) | Q10 |
| 울산광역시교육청 | H10 | 경상북도교육청 | R10 |
| 세종특별자치시교육청 | I10 | 경상남도교육청 | S10 |
| | | 제주특별자치도교육청 | T10 |

**인증키** 칸에 3장에서 받은 NEIS 인증키를 넣습니다. 넣은 키는 화면에 보이지 않고 "● 저장됨"으로만 표시됩니다.

### ③ 날씨

1. **기상청 단기예보**를 고르고, **기상청 인증키** 칸에 키를 넣습니다.
2. **위도·경도**: ②에서 학교 찾기를 썼다면 이미 채워져 있습니다. 직접 넣을 때는 우리 학교 위치로 바꿉니다. 기본값은 배정고등학교(부산 남구)입니다.
   - 위도·경도 찾는 법: 구글 지도에서 학교를 찾아 마우스 오른쪽 버튼을 누르면 맨 위에 `35.1390, 129.0690` 같은 숫자가 나옵니다. 앞이 위도, 뒤가 경도입니다.

### ④ 확인

**지금 가져와 보기**를 누르면 결과 창이 뜹니다. 이렇게 나오면 성공입니다.

```
날씨 (기상청): 14° 맑음, 최저 9° / 최고 17°, 강수확률 10%
학사일정: 앞으로 90일 동안 18건
급식: 앞으로 7일 동안 8끼
```

마지막으로 **확인**을 눌러 저장합니다.

## 5. 화면 고르기 (선택)

| 설정 | 선택지 | 쓰임 |
|---|---|---|
| 화면 크기 | 기본 화면 / 큰 화면 | 큰 화면은 복도·교실 앞처럼 멀리서 볼 때. 가로·세로 모니터를 자동으로 판단 |
| 배경 | 검은 바탕 / 사진 배경 | 사진 배경은 사진 폴더를 고르면 사진을 바꿔 가며 깔고, 시계는 모서리에 작게 표시 |
| 시계 | 24시간 / 초 표시 / 날짜 | |
| 일정 넘김 | 간격 5~30초, 속도 5단계 | 다가오는 일정을 한 건씩 넘겨 보여 줌 |

사진 배경일 때는 키보드 **← / →**로 이전·다음 사진으로 넘길 수 있습니다.

## 6. 여러 PC에 한 번에 설치하기

PC마다 인증키를 넣기 번거로우면, **인증키 파일을 함께 넣은 zip**을 만들어 나눠 쓰세요.

1. 릴리스 페이지에서 **`BaejeongFlip-x.x.zip`**을 받아 압축을 풉니다.
2. 같은 폴더에 메모장으로 파일 두 개를 만듭니다. 각각 키 한 줄만 적습니다.
   - `neis-key.txt`: NEIS 인증키
   - `kma-key.txt`: 기상청 인증키
3. 이 폴더를 교내 공유 폴더나 USB에 두고, 각 PC에서 `설치하기.bat`를 실행합니다.

설치하면 처음 실행할 때 키를 Windows 계정 암호화로 저장하고, 설치 폴더의 키 파일은 자동으로 지웁니다. `kma-key.txt`가 있으면 날씨는 자동으로 기상청으로 설정됩니다.

> **주의:** 키 파일이 든 폴더는 학교 밖으로 공유하지 마세요. 인증키는 발급받은 사람 명의라서, 노출되면 다른 사람이 쓸 수 있습니다.

> 학교 코드·모서리 문구·위도·경도는 PC마다 설정 창의 **학교 찾기**로 한 번에 바꿀 수 있습니다.

공유 폴더나 USB로 복사한 파일은 보통 SmartScreen 경고 없이 실행됩니다. 메신저나 메일로 받은 파일은 **속성 → 차단 해제**를 체크한 뒤 실행하세요.

## 7. 자주 묻는 질문

**날씨가 "작업 시간이 초과되었습니다"로 실패해요.**
학교망에서 해외 날씨 서버가 막힌 경우입니다. 기상청 인증키를 넣으세요(3장). 기상청 키가 있으면 해외 서버가 실패해도 기상청으로 자동으로 다시 받습니다.

**"이 PC는 관리자 정책으로 화면보호기가 고정되어 있습니다"가 나와요.**
교육청이나 학교의 PC 관리 정책 때문입니다. 학교 정보 담당 선생님께 문의하세요.

**화면보호기가 끝나면 로그인 화면이 나와요. 이것도 바꿀 수 있나요?**
로그인 화면은 Windows 보안 화면이라 바꿀 수 없습니다. 교육청 정보보안 지침상 업무용 PC는 로그인을 유지하는 것이 좋습니다.

**화면에 자국(번인)이 남지 않나요?**
시계가 1분마다 조금씩 움직입니다. 모서리 문구와 날씨·일정도 10분마다 자리를 바꿔, 같은 픽셀에 같은 글자가 오래 머물지 않게 했습니다.

**인터넷이 끊기면요?**
마지막으로 받은 일정·급식·날씨를 그대로 보여 줍니다. 날씨는 6시간이 지나면 숨깁니다.
