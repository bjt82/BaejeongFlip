배정플립 - 배정고등학교 플립시계 화면보호기 (BaejeongFlip.scr)

[필요 환경]
Windows 10 / 11 (기본 포함된 .NET Framework 4.x로 실행, 추가 설치 없음)

[설치 - 가장 쉬운 방법]
1. zip 파일을 오른쪽 클릭 → "압축 풀기" (zip 안에서 바로 실행하지 마세요)
2. "설치하기.bat" 더블클릭
3. 대기 시간(분)을 입력하고 Enter → 끝
   - 관리자 권한 필요 없음. %LOCALAPPDATA%\BaejeongFlip 에 복사되고
     화면보호기로 지정됩니다. 다시 로그인할 필요 없이 바로 적용됩니다.
   - "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"

[설치 - 직접 하는 방법]
BaejeongFlip.scr 오른쪽 클릭 → "설치" (Windows 11은 "추가 옵션 표시" → "설치")
→ 열린 화면보호기 설정 창에서 대기 시간을 정하고 "확인".
※ 이 경우 .scr 파일을 옮기거나 지우면 화면보호기가 꺼지니 고정된 폴더에 두세요.

[제거]
"제거하기.bat" 더블클릭

[설정]
화면보호기 설정 창에서 "설정" 버튼:
- 시계: 24시간 형식 / 초 표시(기본 꺼짐) / 날짜·요일 표시
- 화면 크기: 기본 화면 / 시계 중심 화면(시계가 화면 높이의 약 70%, 급식은 시계 아래, 가로·세로 자동)
- 모서리 문구: 학교·부서 (기본: 배정고등학교 / 교육연구부, 비우면 숨김)
- 학사일정 (시계 위): 첫 줄은 오늘 일정(없으면 가장 가까운 일정과 D-day),
  둘째 줄은 다가오는 일정(60일 이내, 최대 8건)을 한 건씩 위아래로 넘기며 보여 줌.
  넘김 간격은 5/8/15/30초 중 선택 (기본 8초). 오늘 일정이 여러 건이면 첫 줄도 넘어감.
  넘김 속도(카드가 접혔다 펴지는 빠르기)는 0.25초 ~ 1.6초 5단계 중 선택 (기본 보통 0.6초).
- 급식 (날짜 아래, 기본으로 켜짐): 점심과 저녁을 10초 이상 간격으로 번갈아 넘기며 표시.
  19시 전에는 오늘 급식(13시 30분이 지나면 저녁부터), 그 뒤에는 다음 급식일.
- 날씨 (시계 위): 현재 기온, 하늘 상태, 최저/최고, 강수확률
  · Open-Meteo: 인증키 없이 바로 사용
  · 기상청 단기예보: 공공데이터포털에서 "기상청_단기예보 조회서비스" 활용 신청 후 인증키 입력
- 배경: 검은 바탕(화면 가득 플립시계) 또는 사진 배경 + 모서리에 작은 시계 판
  · 사진 폴더를 고르면 사진을 무작위로 바꿔 가며 깔고, 시계는 오른쪽/왼쪽 아래 반투명 판에 표시
  · 사진 간격 10초~10분, 맞춤(화면 채우기/사진 전체), 시계 위치(오른쪽 아래/왼쪽 아래/10분마다 번갈아), 크기
- "지금 가져와 보기" 버튼으로 바로 받아 보고 결과(또는 오류)를 확인할 수 있습니다.

[학교 정보 인증키 (NEIS)]
- 인증키 없이도 동작하지만 한 번에 5건까지만 받을 수 있어서, 기간을 나눠 받습니다.
  일정이 많은 달에는 일부가 빠질 수 있으니 open.neis.go.kr 에서 무료 인증키를 받아 넣는 것을 권장합니다.
- 교육청 코드 C10(부산), 학교 코드 7150136(배정고)이 기본값입니다.
- 인증키는 화면에 보이지 않습니다. 설정 창의 인증키 칸에 새 키를 입력하면 교체되고, 비워 두면 저장된 키를 그대로 씁니다.
- 인증키는 Windows 사용자 계정 암호화(DPAPI)로 레지스트리에 저장되어 다른 사용자나 다른 PC에서는 읽을 수 없습니다.
- 설치 파일과 함께 neis-key.txt(NEIS), kma-key.txt(기상청) 가 있으면 처음 실행할 때 읽어서 암호화 저장하고, 파일은 자동으로 지웁니다.
- kma-key.txt 가 함께 설치되면 날씨 서버를 기상청으로 설정합니다. 고른 날씨 서버가 실패하면 다른 서버로 한 번 더 시도합니다.

[정보 받는 방식]
- 화면보호기가 켜져 있을 때 백그라운드에서 받습니다. 날씨는 30분, 학교 정보는 3시간마다 새로 받습니다.
- 받은 정보는 %LOCALAPPDATA%\BaejeongFlip\info-cache.json 에 저장되어, 인터넷이 끊겨도 마지막 정보를 보여 줍니다.
  (날씨는 6시간이 지나면 숨김)
- 받을 정보가 없으면 그 줄은 표시하지 않고 시계가 다시 커집니다.

[끝내기]
마우스를 움직이거나, 클릭하거나, 아무 키나 누르면 꺼집니다.
단, 사진 배경일 때 ← / → 키는 이전·다음 사진으로 넘기고 화면보호기는 그대로 둡니다.

[기타]
- 모니터가 여러 대면 모든 모니터에 표시됩니다.
- 화면 자국을 막기 위해 1분마다 시계 위치가 조금씩 이동합니다.
- 학교·부서 문구는 10분마다 천천히 사라졌다가 다른 모서리에 나타납니다.
  (위 → 아래 → 위 좌우 바꿈 → 아래 좌우 바꿈 순서)
- 시계 위 날씨와 학사일정은 10분마다 좌우 자리를 맞바꿉니다 (위아래로 넘기는 효과, 모서리 문구와 5분 어긋나게).
- 설정은 레지스트리 HKCU\Software\BaejeongFlip 에 저장됩니다.
